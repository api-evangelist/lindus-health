# Lindus Health

Lindus Health is a next-generation contract research organization (CRO) that runs clinical trials end to end for biotech and pharmaceutical sponsors, pairing Citrus — an AI-assisted trial operating system — with centralized patient identification and enrollment, flexible site models, and integrated clinical services from protocol design through database lock.

**No public API.** As of 2026-07-19 Lindus Health publishes no developer API, developer portal, API documentation, or `/.well-known/` discovery surface; the `api.`, `developer.`, `docs.` and `app.` subdomains do not resolve. This profile therefore carries company identity, standards and security artifacts rather than API artifacts.

Backed by: creandum, seedcamp — https://www.lindushealth.com/

## Artifacts

- `packages/` — public package inventory (two open-source CDISC repos; no client SDK, no registry-published package)
- `conformance/` — standards assessment (CDISC SDTM / Dataset-JSON / conformance rules)
- `security/` — TLS, HSTS, SPF, DMARC, DNSSEC and CAA probe results
- `well-known/` — `/.well-known/` discovery probe results (all 404)
- `llms/` — generated `llms.txt` company profile
