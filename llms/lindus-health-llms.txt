# Lindus Health

> Lindus Health is a next-generation contract research organization (CRO) that runs clinical trials end to end for biotech and pharmaceutical sponsors. It combines an AI-assisted trial operating system (Citrus) with centralized patient identification and enrollment, flexible site models, and integrated clinical services from protocol design through database lock. Lindus Health does not publish a public developer API.

## Open source

- [LindusHealth GitHub organization](https://github.com/LindusHealth): Two public repositories; neither is an API client library.
- [django-sdtm-export](https://github.com/LindusHealth/django-sdtm-export): First-party MIT-licensed Django library for exporting clinical model instances to CSV or Dataset-JSON following CDISC SDTM guidelines. Not published to PyPI; install from source. Last updated 2022.
- [cdisc-rules-engine](https://github.com/LindusHealth/cdisc-rules-engine): Fork of the CDISC open-source rules engine for validating clinical datasets against CDISC conformance rules. Upstream owner is CDISC.
